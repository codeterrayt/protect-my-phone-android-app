# Security reporting

Reports about pairing verification, authentication, replay protection, key storage, permission boundaries or unintended data disclosure are welcome.

Use [GitHub private vulnerability reporting](https://github.com/codeterrayt/protect-my-phone-android-app/security/advisories/new) when available, or email **contact@rohanprajapati.dev** with the subject **Protect My Phone security report**. Do not post exploit details, real phone numbers, locations, message contents or keys in public issues.

Include the affected version, Android version, reproduction steps, impact and a minimal example using test devices and synthetic data. Test another person's device only with explicit permission.

Report against the latest release or current main branch. Older releases may need an update before evaluation. There is no guaranteed response time or security-audit certification.
