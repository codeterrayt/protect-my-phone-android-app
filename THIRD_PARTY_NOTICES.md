## Map data and tiles

The interactive map uses the [OpenFreeMap](https://openfreemap.org/) public vector tile service and [MapLibre Native Android](https://github.com/maplibre/maplibre-native)'s renderer. Map data is from [OpenStreetMap](https://www.openstreetmap.org/copyright) and [OpenMapTiles](https://openmaptiles.org/). The map view displays the required attribution. Map tiles require an internet connection; SMS commands and encrypted location replies do not use the map service.
